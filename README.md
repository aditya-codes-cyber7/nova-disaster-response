# 🚨 NOVA Disaster Response

Hey! 👋

NOVA Disaster Response is a project I'm currently working on.

Simple si baat hai — disaster ya emergency ke time par logon ko jaldi help milni chahiye. But kai baar information properly available nahi hoti aur coordination bhi difficult ho jata hai.

So, I thought why not build something which can make this process a little easier.

## 🤔 What is NOVA?

NOVA is basically a platform where people can report emergencies, share important information and help volunteers or emergency teams coordinate better.

The main goal is to bring important emergency-related things to one place instead of searching everywhere during a critical situation.

## 🚀 Features

Currently, I'm working on features like:

- 🚨 Quick SOS / Emergency reporting
- 📍 Location sharing
- 📢 Emergency alerts
- 🗺️ Disaster-related information
- 👥 Volunteer coordination
- 📊 Simple dashboard

## 🛠️ Tech Stack

For building this project, I'm using:

- HTML
- CSS
- JavaScript
- React
- Firebase
